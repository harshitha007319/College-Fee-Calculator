# 🎓 College Fee Calculator

A simple and user-friendly web application developed to calculate and manage college fee details.

## 📌 Project Overview

The College Fee Calculator is a web-based mini project that helps students calculate their total college fees based on different fee categories.

The application also shows the amount already paid, remaining fee amount, and payment status.

## ✨ Features

- 👤 Student Name
- 🆔 Register Number
- 💰 Tuition Fee
- 🏠 Hostel Fee
- 🚌 Transport Fee
- 📝 Exam Fee
- 📚 Other Fee
- 💵 Amount Paid
- 🧮 Automatic Total Fee Calculation
- 📊 Remaining Fee Calculation
- ✅ Payment Status
- 🔄 Reset Option
- 💻 Simple and User-Friendly Interface

## 🧮 How It Works

The application calculates the total fee using:

```text
Total Fee =
Tuition Fee +
Hostel Fee +
Transport Fee +
Exam Fee +
Other Fee
The remaining fee is calculated using:

Remaining Fee =
Total Fee - Amount Paid
Payment Status
Paid → Full amount has been paid
Partially Paid → Some amount has been paid
Pending → No amount has been paid
